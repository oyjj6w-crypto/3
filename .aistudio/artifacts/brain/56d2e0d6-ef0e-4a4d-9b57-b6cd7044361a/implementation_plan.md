# 多视窗快捷控制与自定视窗组合预设增强方案 (已更新确认)

本方案根据用户反馈已重新确认并校准核心需求：彻底删除磁吸按钮右侧显示**阿拉伯数字“4”**的按钮（原4图/视窗翻转按键）、将磁吸按钮内部图标替换为纯汉字“磁吸”，并在窗口最大化/隐藏控制区后新增 3 个可自定义按钮名称与视窗显示隐藏状态的快捷组合按钮（单击秒切，长按自定义配置并持久化）。

---

## User Review & Critical Decisions

> [!IMPORTANT]
> **需求确认与核心意图对齐**：
> 1. **确认删除目标**：正是右上角**磁吸按钮旁边**、显示**阿拉伯数字“4”**的按钮（在 Android 原生端对应 `Text(text = "4")` 翻转按钮，Web 端对应翻转按钮），本次将予以彻底移除。
> 2. **磁吸按钮文字替换**：磁吸按钮内部不再使用图标，直接呈现高对比度的加粗汉字“**磁吸**”。
> 3. **新增 3 个快捷按钮与自定义配置**：
>    - 位于每个窗口单独的最大化/隐藏（👁/放大）控制按钮组后面；
>    - 默认添加 **3 个快捷预设按钮**（初始默认预设：预设1显示 W1、预设2显示 W1+W2、预设3显示全部 W1~W3）；
>    - **单击**：直接应用对应视窗显示/隐藏组合；
>    - **长按**：呼出配置弹窗，允许用户自由勾选 W1、W2、W3 的显隐，并支持**自定义修改按钮的文字标识**（如“全览”、“BTC单屏”等），保存后即时生效并持久化存储。

## 1. Overview & Core Concept

- **解决的核心痛点**：
  1. 交易员在多币种比对时，经常需要在“单屏特写”、“双屏比对”、“三图全景”之间切换，过去需要频繁逐个点击窗口的眼睛隐藏按钮；
  2. 磁吸按钮旁边的阿拉伯数字“4”按钮在当前使用场景下多余且占用空间；
  3. 磁铁图标不及直接展示汉字“磁吸”清晰直观。
- **核心价值**：
  1. **直观清晰**：清除数字“4”按键，磁吸按钮改名“磁吸”，顶栏布局干净利落；
  2. **毫秒级批处理**：新增 3 个快捷按钮，一键切换常用多视窗形态；
  3. **个性化命名**：长按支持自定义按钮文字与视窗显隐组合，满足个性化看盘习惯。

### 交互细节设计 (Interaction Details)

1. **彻底移除数字“4”按钮**：
   - Android 原生端（`TradingMultiViewScreen.kt`）中，删除磁吸按钮旁 `Text(text = "4")` 的按键 Box 及关联的 `triggerInvert4Charts`；
   - Web 端（`App.tsx`）中，彻底移除磁吸按钮旁的翻转按钮。
2. **“磁吸”按钮纯汉字展示**：
   - 保持标准的 30×30 dp/px 方形圆角规格；
   - 内部文字为“**磁吸**”（11px 加粗，`font-bold`），未激活时呈高质感 Slate 灰白，激活时呈鲜明半透明玫瑰红（`bg-rose-600/20 text-rose-400`），状态清晰醒目。
3. **3 个快捷预设按钮**：
   - 紧随单个窗口的最大化/隐藏按钮组之后渲染；
   - **单击行为**：瞬间激活对应视窗显隐组合，当前激活的预设呈现高亮边框和主题微光；
   - **长按行为**（桌面长按或移动端长按 500ms）：
     - 弹出《快捷按钮设置》模态弹窗；
     - 包含：**按钮文字标识输入框**（允许修改为“大饼单图”、“全景”等任意字符，最多 6 个字）、**W1/W2/W3 视窗显示勾选框**（Checkbox）；
     - 具备安全防护：若全部未勾选，提示“至少保留一个窗口显示”，防止黑屏死锁；
     - 保存后实时更新顶栏按钮文字与显隐状态，并保存至持久化存储中。

## 3. Key Product Decisions & Trade-Offs

- **决策 1：明确“4”字按钮的归属与清除范围**
  - *分析*：用户明确指出是“右上角的阿拉伯数字 4 的按钮，在磁吸按钮旁边的这个按钮”。该按钮原先作为“Alt+I 4图翻转”的触发器（在 Compose 代码中为 `Text("4")`）。
  - *处理*：在 Web 端和 Android 原生 Compose 代码中均精确斩断并移除该按钮，绝不误删其他按钮。
- **决策 2：快捷按钮支持自定义文字标识与宽度自适应**
  - *分析*：用户要求“可以让我自定义文字标识”。
  - *处理*：快捷按钮采用 `min-w-[32px] px-2 h-[30px]` 的自适应胶囊/圆角矩形样式，无论用户命名为“1”、“双屏”还是“BTC+ETH”，都能优雅呈现，文字居中、排版精致。
- **决策 3：预设持久化与多端同步**
  - *处理*：Web 端保存在 `localStorage`，Android Compose 端保存在 `SharedPreferences`，每次刷新页面或重新打开 App 均保留用户的自定义名称与显隐组合。

### 修改文件及改动要点

1. **`src/types.ts`**：
   - 新增 `WindowVisibilityPreset` 接口：
     ```typescript
     export interface WindowVisibilityPreset {
       id: number;
       name: string;        // 自定义文字标识，如 "预设1"
       visibleIds: number[]; // 勾选显示的窗口ID数组，如 [1, 2]
     }
     ```
2. **`src/App.tsx`**：
   - 彻底删除磁吸按钮旁边的“翻转”（数字 4 / 翻）按钮；
   - 磁吸按钮 `<Magnet className="w-3.5 h-3.5" />` 替换为 `<span className="text-[11px] font-bold">磁吸</span>`；
   - 在 W1~W3 眼睛/最大化按钮之后，循环渲染 3 个预设快捷按钮；
   - 快捷按钮绑定单击与长按事件（支持移动端 touch 与 PC mouse），实现长按配置模态框；
   - 实现预设配置与应用逻辑，更新各窗口的 `isHidden` 状态。
3. **`src/data/androidProjectSource.ts`**（Android 原生代码同步）：
   - 在 `TradingMultiViewScreen.kt` 中删除 `Text(text = "4")` 4 图翻转按键；
   - 磁吸按键由 `Icon(CenterFocusStrong)` 替换为 `Text(text = "磁吸", fontSize = 11.sp, fontWeight = FontWeight.Bold)`；
   - 在顶栏窗口显隐按钮后新增 3 个 Compose 预设快捷按钮与长按配置 Dialog。
