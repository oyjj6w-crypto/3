# 虚拟触控板视觉增强与纯净化改造计划

## 1. 目标与需求概述
根据用户选择与反馈，对浮层虚拟鼠标触控板进行视觉优化：
1. **背景保持 30% 高透视**：触控板内部背景底色保持半透明（透视底层 K 线走势），但移除外层容器的全局 `.alpha(0.3f)`，避免外围线条被淡化至看不清。
2. **外围使用不透明高亮线条**：在面板最外层轮廓使用 100% 不透明的高对比度实线（1.5dp 天蓝色 `#38BDF8` 或亮蓝边框），令触控板在任何 K 线背景下均具有清晰可见的物理边界。
3. **触控感应区彻底纯净化**：移除触控板中央的 `Icons.Default.TouchApp` 手指点击图标与 `单指滑动 · 轻点左键 · 长按右键` 说明文字，呈现纯净深色底色，盲操无任何视觉干扰。
4. **保留现有完整功能**：左侧 36dp 紧凑型手柄拖拽、灵敏度切换、Del 快捷键、全套鼠标按键及双向手势驱动均保持原状。

---

## 2. 详细技术方案

### 2.1 架构与布局调整 (`VirtualMouseTrackpad.kt`)
* **外层容器样式重构**：
  * 移除根容器 `Box` 上的全局 `.alpha(0.3f)`，使边框线条不再被全局 alpha 稀释；
  * 外层容器边框采用 `BorderStroke(1.5.dp, Color(0xFF38BDF8))`（100% 不透明实线），配合清晰的圆角 `RoundedCornerShape(12.dp)` 与微阴影 `shadow(elevation = 12.dp)`；
  * 背景颜色设置 `Color(0xFF0B111E).copy(alpha = 0.30f)`，精准达成 30% 透视度。
* **左侧手柄与子模块透明度协调**：
  * 左侧 36dp 拖拽条背景保留 `Color(0xFF1E293B).copy(alpha = 0.40f)`，配合不透明的浅蓝边框与拖拽图标；
  * 顶部标题栏背景与按钮区域使用半透明背景，文字与图标保持高清晰对比度。
* **触控感应区 (`Touchpad Gesture Area`) 纯净化**：
  * 保留原有的手势监听逻辑（滑动、轻点左键、长按右键、拖拽）；
  * 彻底移除内部的 `Column { Icon(TouchApp); Text("单指滑动 · 轻点左键 · 长按右键") }` 组件；
  * 感应区背景采用半透明深色 `Color(0xFF060911).copy(alpha = 0.35f)`，边框保留轻微的暗灰实线，视觉极致纯净。

## 3. 验证计划
1. **编译检查**：运行 `compile_applet` 确保 Compose 代码编译无误。
2. **视觉与交互验证**：
   * 打开触控板，确认外围拥有清晰、不透明的 1.5dp 高亮线条轮廓；
   * 确认触控板下方 K 线图仍有 30% 半透明透视效果；
   * 确认滑动触控区域内已无手指图案与任何文字干扰；
   * 验证左侧 36dp 手柄拖拽、触控板单指滑动移动光标、轻点左键与右键菜单响应完全正常。
